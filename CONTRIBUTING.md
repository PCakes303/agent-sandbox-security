# Contributing

Use Python 3.10+. Install the pinned test dependency with `python -m pip install -r requirements-dev.txt`, then run `python -m unittest discover -s tests -v` before submitting changes. The test runner is Python's standard-library `unittest`; schema-parity tests also require the pinned `jsonschema` package. Add negative tests for malformed policy, excessive limits, stale or missing stop state, and authorization failures. Changes to execution authority, isolation, stop-state semantics, or resource limits require an ADR and security review. Do not include live credentials or personal data.
